# Dashboard (`soroban-budget-dashboard`)

The `soroban-budget-dashboard` provides an intense, data-first Cyberpunk visualization frontend for monitoring historical resource data.

Instead of scrolling through GitHub PR comments, developers can access this Vite/React application to view interactive line charts powered by `recharts`. It directly queries the `snapshot.json` files generated by the GitHub Action and plots them over time, allowing maintainers to instantly spot trends in CPU, Memory, and Storage consumption.

## Architecture

The dashboard is built entirely on the client side using React and Vite. It does not require a backend server.
When a user opens the dashboard, it uses the GitHub REST API (Octokit) to fetch the cached `snapshot.json` files from the repository's action artifacts or directly from the `main` branch.

## Local Development

```bash
git clone https://github.com/BudgetGate/soroban-budget-dashboard.git
cd soroban-budget-dashboard
npm install && npm run dev
```
